# Refactoring Skill

Use this skill when improving existing code without changing its behavior.

Focus on:
- simplifying complex files
- removing duplication
- improving naming
- splitting services
- separating business logic from routes/views
- improving error handling
- making code easier to test
- preserving current behavior

When refactoring:
1. First explain the problem in the current code.
2. Then propose a safer structure.
3. Refactor step by step.
4. Avoid big rewrites unless necessary.
5. Keep compatibility with the existing project.
6. Prefer small, reviewable changes.
