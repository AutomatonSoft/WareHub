# System Design Skill

Use this skill when designing backend architecture, SaaS systems, APIs, databases, queues, workers, AI agents, CRM systems, integrations, or deployment architecture.

Focus on:
- clear service boundaries
- database schema design
- API structure
- background jobs
- caching
- scalability
- fault tolerance
- security
- observability
- deployment with Docker/Nginx/PostgreSQL/Redis

When responding:
1. Start with the simplest working architecture.
2. Explain why each component is needed.
3. Show folder structure when useful.
4. Show data flow.
5. Mention tradeoffs.
6. Avoid overengineering unless the project requires it.
