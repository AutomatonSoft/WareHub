# eBay: scope и приёмка

## Текущий scope

- Новые объявления создаются через Inventory API. Main EAN остаётся идентификатором исходного товара; зарезервированный новый SKU используется для нового объявления.
- Inventory: загрузка, создание, редактирование, снятие публикации и повторная публикация.
- Legacy: загрузка и редактирование существующих объявлений. Sofort List activate/deactivate поддерживает только FixedPriceItem без вариаций и с сохранённой однозначной привязкой.
- Создание новых Legacy-объявлений, автоматическая миграция Legacy в Inventory и переключение Legacy-вариаций не входят в текущий scope.
- Проверка размеров с удалением дублей и фото меньше 500 px по длинной стороне применяется только к Inventory publish/relist. Исходные файлы не удаляются. Непроверяемое изображение или отсутствие подходящих фото останавливает публикацию.

## Разрешение на внешнюю проверку

До записи на eBay согласовать окружение (Sandbox или production), аккаунт, тестовые EAN/SKU, разрешённые изменения цены/остатка/фото, возможные комиссии и конечное состояние объявления. Не создавать объявления в production лишь для запуска теста.

## Матрица для каждого аккаунта JV, XL, DEP

| Шаг | Действие | Проверка на eBay |
| --- | --- | --- |
| 1 | Опубликовать тестовый Inventory-товар | Есть Item ID, Offer ID, карточка доступна и принадлежит правильному продавцу |
| 2 | Загрузить товар повторно | SKU, исходный EAN, цена, остаток и фотографии совпадают |
| 3 | Изменить цену и количество | Прочитать Inventory/Offer заново; проверить цену на витрине |
| 4 | Удалить и добавить согласованное фото | Прочитать imageUrls и проверить галерею на витрине |
| 5 | Деактивировать | Offer UNPUBLISHED; объявление больше нельзя купить |
| 6 | Активировать повторно | Offer PUBLISHED; объявление снова доступно, нет дубликата |
| 7 | Повторить activate | Нет нового объявления или дублирующей публикации |
| 8 | Проверить маленькое фото и дубль | Подходящие фото остаются, список исключённых виден в результате |
| 9 | Проверить недоступные/только маленькие фото | Публикация блокируется; ошибочный успех не показывается |
| 10 | Проверить согласованный существующий Legacy FixedPriceItem | Загрузка, редактирование, deactivate/relist; после relist сохранить новый Item ID |

Для каждого шага записать account, SKU, Item ID, Offer ID (для Inventory), job_id, результат API и фактическое состояние на eBay. `completed` — завершение задачи, а не доказательство успешной публикации. После проверки вернуть согласованное состояние товара.

Локальные тесты с mock API проверяют контракты и порядок запросов, но не заменяют эту внешнюю матрицу.
